# 🎓 Profesor Virtual de Idiomas (Inglés 🇬🇧 · Italiano 🇮🇹)

> Aplicación web progresiva (PWA) de aprendizaje y práctica conversacional de idiomas por voz en tiempo real con inteligencia artificial (**Gemini Live API**), con detección y corrección instantánea de pronunciación, gramática y vocabulario.

Desarrollado y creado por el **Ing. Comercial Kristhian Conde Zegarra** con soporte de Inteligencia Artificial.

---

## 🌟 Características Principales

- 🎙️ **Conversación por voz en tiempo real:** Comunicación bidireccional fluida con audio nativo (Gemini 3.8 Live) en inglés y en italiano.
- 🗣️ **Corrección instantánea de pronunciación:** Detección de fonemas y acentuación en vivo, con tarjetas visuales que muestran la pronunciación fonética y la forma correcta.
- 💬 **Soporte multimodal (Voz + Texto):** Si no cuentas con micrófono o hay ruido, puedes escribir tu mensaje y la profesora te responderá por voz.
- 🧭 **Ruta pedagógica y niveles adaptativos:**
  - 🌱 **Desde cero (A0):** Explicaciones bilingües guiadas en español para quienes no tienen ninguna base previa.
  - 🔍 **Detectar mi nivel:** Saludo accesible que detecta la fluidez y adapta el vocabulario automáticamente.
  - **A1 hasta C1:** Práctica avanzada para situaciones profesionales.
- 💼 **Más de 40 temas y profesiones:** Inspector de migraciones, entrevistas de trabajo, medicina, leyes, ingeniería, hotelería, turismo, negocios y temas libres.
- 📱 **PWA (Instalable en cualquier celular o PC):** Funciona en Android, iPhone, Windows y Mac, sin necesidad de descargar de tiendas de aplicaciones.
- 🔒 **100% Privado y Gratuito:** Cada usuario gestiona su propia clave gratuita de Google AI Studio almacenada únicamente en su navegador.

## 🚀 Instalación y Desarrollo Local

```bash
# Clonar el repositorio
git clone <URL_DEL_REPOSITORIO>
cd profesor-virtual-idiomas

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Ejecutar pruebas unitarias
npm test

# Compilar para producción
npm run build
```
